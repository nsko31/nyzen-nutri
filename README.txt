INSTALLATION SUR IPHONE
Une application web doit être publiée sur une adresse HTTPS pour que Safari puisse l'ajouter proprement à l'écran d'accueil et autoriser l'accès caméra.
1. Publie le contenu de ce dossier sur un hébergement HTTPS statique (par exemple GitHub Pages).
2. Ouvre l'adresse publiée dans Safari sur l'iPhone.
3. Touche Partager > Ajouter à l'écran d'accueil > Ajouter.
4. Lance NYZEN NUTRI depuis l'icône.

FONCTIONS
- Profil (âge, taille, poids, activité, objectif)
- Estimation indicative des besoins pour adultes uniquement
- Journal par date et ajout manuel avec calcul au gramme
- Calories, protéines, glucides et lipides
- Recherche code-barres via Open Food Facts
- Scan caméra (nécessite HTTPS et connexion)
- Historique des jours et évolution du poids
- Export / import JSON
- Données stockées localement dans le navigateur

LIMITES ET PRÉCAUTIONS
- Pas d'abonnement, compte ou backend.
- Les données produits sont fournies par Open Food Facts et peuvent être incomplètes ; vérifie l'étiquette.
- La recherche code-barres nécessite Internet.
- La caméra nécessite un navigateur compatible, une permission accordée et HTTPS.
- Pour les moins de 18 ans, aucun objectif calorique de perte ou surplus n'est calculé. Le suivi reste un journal descriptif ; demande conseil à un professionnel de santé pour les objectifs nutritionnels.
- Les données sont locales à ce navigateur/appareil. Exporte régulièrement une sauvegarde ; effacer les données du navigateur peut les supprimer.
